# CCDC-HIVE

HIVE (**H**osted **I**nfrastructure for **V**irtual **E**xercises) is a system designed to enable quick setup and teardown for practice scenarios for a CCDC competition team.
This repository outlines the vision and documents the current status of HIVE.
